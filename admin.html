How Cross-Device Sync Works
Admin creates trip → Trip saved to JSONBin cloud → Bin ID encoded in WhatsApp URL
Rider opens link → Fetches trip from JSONBin using Bin ID → Fills POD → Updates same bin
Admin clicks Refresh → Fetches all bins → Sees completed PODs with photos, signature, invoice copy

Link Expiry: Once rider closes the trip, the link shows "Trip Already Closed" to anyone reopening it.
Mandatory Images: Rider cannot close trip without at least 1 delivery photo + stamped invoice photo.
