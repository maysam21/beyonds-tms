Data management removes records from your local browser index. JSONBin cloud bins are not automatically deleted (visit jsonbin.io to delete bins from cloud). Use these tools to clean up your admin view.
Delete Individual Trips
Select a specific trip to remove from your admin panel. The trip data remains in JSONBin cloud unless manually deleted there.
⚠ Danger Zone
Clear All Trip Records
Removes all trips from local admin panel index. POD records also cleared. Cannot be undone.
Clear Closed Trips Only
Removes only trips with status "Closed" (completed deliveries). Active trips remain untouched.
Factory Reset
Clears all local data including API key and settings. You will need to re-enter your JSONBin key. Use only if reconfiguring the system.

Sync Notes
Trip data lives in JSONBin cloud. Admin and rider access the same bin using the bin ID in the WhatsApp link.

Link uses URL fragment (#). WhatsApp never mangles fragments, so the API key travels safely to the rider's phone.

Link expires permanently once rider closes trip — status set to "Closed" in cloud.
